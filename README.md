# 香港中文課程 K1–S6

由幼稚園 K1 到中六，按香港教育局中國語文課程架構整理的靜態教學網站：五大學習階段、十五個年級，涵蓋**聆聽、說話、閱讀、寫作、文化、詞彙**六大範疇，每級附教學內容、詞彙表（粵拼）、建議篇章，以及**三個難度**的即時批改測驗。

## 網站結構

```
index.html          課程總覽（階段篩選、年級卡、範疇說明、課程依據）
grade.html?g=p3     年級頁：六大範疇學習重點與教學示例、詞彙表、建議篇章、測驗入口
quiz.html?g=p3&level=2   測驗：三級難度，每份 10 題，即時批改＋逐題解釋
bank.html?g=p3      題庫：該級全部題目（≥50 題），可按題型篩選、顯示答案
assets/css/style.css
assets/js（內嵌於頁面，無需建置）
assets/data/core.js      階段／年級／範疇定義與工具函數
assets/data/k.js         K1–K3
assets/data/ks1.js       P1–P3
assets/data/ks2.js       P4–P6
assets/data/ks3.js       S1–S3
assets/data/ks4.js       S4–S6（DSE）
assets/data/extra.js     各級補充題（語文知識、量詞、標點、成語、古詩、文言、文化、寫作）
assets/js/questions.js   題目池：由詞彙自動生成五類題＋手寫題＋階段綜合題
```

純靜態、無依賴、無建置步驟；可直接用任何靜態伺服器或 GitHub Pages 發佈。

## 內容範圍

| 階段 | 年級 | 重點 |
|---|---|---|
| 幼稚園 | K1–K3 | 聽說、繪本共讀、前書寫、生活識字、節日與兒歌 |
| 第一學習階段 | P1–P3 | 識字與筆順、部首、四素句、短文閱讀、看圖寫作 |
| 第二學習階段 | P4–P6 | 記敘／描寫／說明、篇章結構、古詩文啟蒙、議論入門 |
| 第三學習階段 | S1–S3 | 文言虛詞與直譯、四類文體、實用文、文學與文化常識 |
| 第四學習階段 | S4–S6 | 12 篇指定篇章、卷一閱讀、卷二實用＋命題寫作、應試策略 |

## 測驗設計

全站共 **849 題**，每級 51–59 題、14–19 類題型。

- **自動生成（每級 40–50 題）**：詞義、釋義選詞、粵拼、聆聽（粵語語音）、例句填空
- **手寫題（每級 9–13 題）**：量詞、標點、部首、成語、古詩、文言、文化、文體、寫作知識、邏輯謬誤
- **階段綜合（每級 4 題）**：跨級比較與較難題目

每次測驗隨機抽 10 題，同一題型最多 2 題；每題皆有答案與解釋，完成後顯示分數與逐題檢討，可重做（題目與選項重新洗牌）。

## 課程依據

- 教育局《中國語文教育學習領域課程指引（小一至中六）》（2017）
- 教育局《中國語文課程指引（小一至小六）》（2023）及其附錄「建議篇章（文言經典部分）」
- 香港考試及評核局 2024 年起中國語文科評核安排（卷一閱讀、卷二寫作、校本評核）
- 高中 12 篇指定文言篇章

詞彙量、年級對應與題目屬教學示例，各校課本進度不同，宜以校內課程為準。
